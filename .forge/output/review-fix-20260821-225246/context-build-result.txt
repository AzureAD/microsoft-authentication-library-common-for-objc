## Build Context Summary — PR #1947

### 1. System Context

This PR modifies `MSIDBrowserNativeMessageGetTokenResponse`, a browser-native-message response serializer in the MSAL iOS/macOS shared library (`IdentityCore`). It sits in the **broker operation response** layer (`IdentityCore/src/broker_operation/response/browser_native_message_response/`), responsible for shaping token-endpoint data before it's sent to a browser caller via native messaging.

The change addresses a **CWE-201 information-disclosure** bug: the `jsonDictionary` method previously forwarded the full `MSIDTokenResponse.jsonDictionary` (including refresh tokens, client_info, FoCI, ADI, and arbitrary server fields) to browser callers who should only see the browser contract fields.
